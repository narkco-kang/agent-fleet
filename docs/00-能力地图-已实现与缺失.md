## 0. 一句话定位

AgentFleet = **多设备智能体舰队**：每台设备是一支本地蜂群（设备上已装的 codex/claude/grok/cursor 等真实 CLI agent 平台是工蜂），backend 统一跨设备调度。原名 AgentMesh。

- 目录 `agent-mesh/`（npm workspaces，scope `@agentfleet/*`）
- GitHub https://github.com/narkco-kang/agent-fleet（public / MIT / main）

## 5. 已知事实校正（凭记忆容易写错，务必核对）

1. **WorkBuddy 执行路径 = HTTP 动态端口网关 + session reply 轮询**（非 ACP `--serve --acp`，代码注释与实现不符）
2. **NeuralGraph 布局 = CSS Grid 两栏**（设备内嵌 agent 可折叠 | 任务可折叠），依赖有 d3-force 但源码零 import
3. **记忆检索 = BM25 + 语义向量（Xenova）+ Jaccard + 图遍历 四路 RRF**（`hybridSearchAsync`）；五类语义分层 + Dreaming + 遗忘衰减 + 写入溯源已实现，只写语义索引不写账本
4. **个人微信 = 纯占位**；成本核算 = 有（pricing.ts + usage_records.cost）
5. **RRF 重排已实现**——本项目唯一曾被我误判为"缺失"的能力，现已修正
6. **Orca 不是"工作台"，是完整 coordinator 编排系统**（114,746★，有 DAG/决策门/熔断/联邦跨主机/turn 队列）。之前对比报告"Orca 无自动路由/断线检测/跨设备调度"的判断**已证伪**，详见 `deliverables/Orca调度流程深度调研与对标.md`
7. **跳过鉴权的 env 名是 `AGENTMESH_SKIP_AUTH`（历史遗留，项目曾名 AgentMesh），不是 `AGENTFLEET_SKIP_AUTH`**。代码已兼容两者，但老文档/脚本里 AGENTMESH 才是正名，别写错导致设备注册被拒（token 校验失败 → 设备反复重试 register 死循环）
8. **设备任务终态由 `onDeviceTaskResult` 权威收口**：`onDeviceTaskEvent` 不再对终态 status 置终态/finalize——否则设备成对发送的 `TASK_RESULT` 被「终态幂等」丢弃，`finished_at`/`result_text` 永不落库（真实设备 e2e 延迟全 0）。跨设备伪造 result/event 由 transport 传入的 sender deviceId 拒绝
9. **doubao 有 TRAE CLI**（字节 AI 编程命令行，2026 发布，headless 待实测）；cody（`sourcegraph cli` 是代码搜索工具）/windsurf 仍无 headless 编码 agent CLI
10. **circuitBreaker ≠ HealthBoard**：前者是 device+agent 维度的内存熔断器（调度用），后者是持久化、单一写入者、连续 3 次才告警的全局健康条目（可观测用）。两者并存，不要互相替代
11. **老库新增列必须走 `runMigrations()`**：SQLite 的 `CREATE TABLE IF NOT EXISTS` 只建新表不改老表；`action_confirmations` 的 `policy_version/policy_notice/reason` 三列均在 `backend/src/db/database.ts` 补列，否则老库 INSERT 报 `no such column`
12. **`actionGuard.confirm()` 的 executed 语义**：表示「副作用已在事务内登记待执行」，不是业务终态；真正的执行由 `effectQueue` 提交后派发，失败会在队列里退避重试（`/api/system/effects` 可查）
13. **模型体检成功路径必须同时满足「本机有网关」+「业务 ref 有别名」**：`MODELGATEWAY_URL` 默认 `127.0.0.1:18765`；角色路由里 8 个 primary 是 DSH 风格虚拟 ref（`mgs-claude/group/strong`、`gpt/gpt-6.1-sol`…），未配别名时 `ProviderPool.resolve()` 降级到 `kilo-free` **却仍把虚拟名原样发给上游**，必定 400/空响应。别名在本机 `.workbuddy-ai/modelgateway-aliases.json`（gitignore），`MG_MODEL_ALIASES` env 可覆盖同名做单点故障注入，`MODELGATEWAY_LOCAL_CONFIG=0` 让集成测试彻底隔离本机配置
14. **本机启动链已带网关**：`scripts/dev-local.mjs` 先探 `18765/health`，无健康实例才 spawn；单独启动用 `scripts/start-modelgateway.sh`。LaunchAgent plist 已生成在 `~/Library/LaunchAgents/`，但当前执行上下文 `launchctl bootstrap` 返回 I/O error，需真实 Terminal 手动注册（见 `docs/29` §9.4）
